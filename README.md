# TPBot Nederlands

Nederlandstalige MakeCode-extensie voor de ELECFREAKS TPBot.

Deze extensie is bedoeld voor gebruik in het basisonderwijs. De technische code is gebaseerd op de officiële [ELECFREAKS TPBot-extensie](https://github.com/elecfreaks/pxt-TPBot). De blokken en documentatie zijn vertaald en waar nodig herschreven naar duidelijke leerlingentaal.

## Toevoegen aan MakeCode

Open [Microsoft MakeCode voor micro:bit](https://makecode.microbit.org/), kies **Geavanceerd → Extensies** en zoek naar `pxt-tpbot-nederlands` of voeg deze repository-URL toe:

`https://github.com/aaronwillaert/pxt-tpbot-nederlands`

## Voorbeelden

```typescript
TPBot.headlightColor(0xff0000)
TPBot.setTravelSpeed(TPBot.DriveDirection.Forward, 50)
basic.pause(1000)
TPBot.stopCar()
```

## Voor leerkrachten

De extensie behoudt de functionaliteit van de officiële TPBot-code. Alleen de zichtbare blokteksten, Nederlandstalige documentatie en extensiemetadata zijn aangepast. Controleer bij een nieuwe officiële TPBot-release of de code opnieuw moet worden gesynchroniseerd.
